## The Stack 🧰

Nothing here needs a DAW or a video editor.

- **Grok Imagine** (`image_edit` / `image_to_video`) for stills and idle loops
- **Venice** `elevenlabs-music` for instrumental tracks
- **ffmpeg** + a few dozen lines of Python for queue/retrieve, duration checks, and loop trimming
- A local `index.html` so you can actually *listen* while you look

The visual bible is the existing mascot: flat 2D vector, plum / gold / moonlight, adult superhero proportions. Not painterly. Not chibi stickers. If a generation looks like a die-cut emoji, throw it out.

## 1. Freeze the empty rooms 🏙️

The single most useful rule: **paint the room before you paint the people.**

We generated empty rooftops, fire escapes, and interiors first and then **never overwrote them**. Characters get composited onto those plates. Collaging stickers onto the same rooftop over and over is how you get two art styles in one frame.

![Empty dusk rooftop plate](/images/blog/heroic-lofi-empty.jpg)

*Frozen empty plate for Cape On, IDE Open. The dressed scene is this plus two people — not a new rooftop.*

Folder layout we ended up with:

```
heroic-lofi/
  characters/          # boards + fullbody refs
  scenes/empty/        # locked plates — do not overwrite
  scenes/dressed/      # stills with/without cast
  scenes/archive/      # every still you replaced, in case you want it back
  audio/               # MP3 masters
  videos/loops/        # short Imagine idles
  videos/masters/      # muxed loop + audio
  scripts/             # Venice queue/poll
  index.html           # local preview
```

If you only remember one thing: identity lives in `characters/`, setting lives in `scenes/empty/`, and a dressed still is *those two things combined*.

**Save the prompt with every plate you keep.** Halfway through the album, new plates started coming back 3D, in perspective, or with heavy black outlines. The fix was to dig up the prompts behind the plates we'd kept and reuse their wording: straight-on, flat color, no outlines, no 3D perspective. That's why every scene and music prompt now lives behind a hover on the [album page](https://lofi.workingdevshero.com).

## 2. Boards first, scenes second 🦸

![Hero character board](/images/blog/heroic-lofi-hero-board.jpg)

![Dimitris character board](/images/blog/heroic-lofi-dimitris.jpg)

Don't invent a teammate inside the scene. Lock a **character board** on a flat plum background, get the human to say yes, *then* drop them into the plate.

What burned us:

- **Sticker boards vs scene art.** The original busts were cute die-cut stickers. The rooftop stills were adult 2D vector. Putting sticker-Dimitris next to scene-Hero looked like two shows. Style-lock from a *scene* you already like, not from the kawaii sheet.
- **Edit chains drift.** Five `image_edit`s on the same file will give you bug eyes, then a Ghibli cousin, then a different person. When a board is close, go back to the last version you approved and make one new edit from there. Don't keep asking the model to "fix the eyes" on top of its last attempt.
- **Named extras need their own silhouette.** Dimitris started as a green-suited Hero clone: same mask, same white lenses, same magenta boots, same beard. The version that worked is a *younger sidekick* — no mask, short beard, brown eyes, green suit, green boots, slimmer than the lead. Distinguish costume **and** age **and** proportions.
- **Head size is a scene problem.** A board can look fine and still balloon in the wide shot. Prompt the dressed still with a concrete comparison: *"his head is the same size as the sitting hero's head."* Then look. Then do it again.

For Hero we eventually stopped generating a new bust at all. We cropped the original Working Dev's Hero rooftop plate and ran a real background-removal pass so the drawing — including the small white mask lenses — stayed the drawing.

That's the one kind of hand edit that paid off: a deterministic operation that *preserves* the original pixels. Everything else we tried by hand — patching a railing, painting eyes white, stamping text onto a billboard — looked worse than re-prompting. Unless the fix is trivial (a crop, a trim), go back to the edit model for stills and regenerate for video.

## 3. Instrumentals on Venice 🎹

Venice exposes ElevenLabs Music as `elevenlabs-music`. There is no bitrate knob (we got 128 kbps). Re-encoding to 192 kbps does not add quality. If you want WAV or `mp3_44100_192`, that's a [Venice feature request](https://featurebase.venice.ai).

Queue, then poll retrieve. Retrieve often returns **raw MP3 bytes** (`ID3` / `0xff`), not JSON.

```python
payload = {
    "model": "elevenlabs-music",
    "prompt": prompt,
    "duration_seconds": 154,   # hard-cap 179 if you care about Shorts
    "force_instrumental": True,
}
# POST https://api.venice.ai/api/v1/audio/queue
# then poll POST /audio/retrieve with {"model": "elevenlabs-music", "queue_id": qid}
```

**Vary the lengths.** Twenty tracks at exactly 180 seconds would get the same song shape twenty times. We used three families — short (96–118s), mid (132–154s), and long (162–178s) — and put the length in the prompt too, so the model writes the arrangement to fit. Pricing made this free: when we made the album, anything from 121 to 180 seconds cost the same ($2.08), and 61–120 seconds was $1.38. The first pass at all twenty tracks came in under $40.

Prompt shape that behaved:

```
Instrumental lo-fi hip hop, 75 BPM, E minor, about 2 minutes 34 seconds.
Deep sub bass, Rhodes, faint server-fan bed. Intimate workshop mood.
Start with vinyl, bass at 0:16, drums at 0:32.
No vocals, no lyrics, tape saturation, loop-friendly ending.
```

Gotchas:

- **Do not name artists.** Venice 422s on content policy. Describe the *sound*.
- **`force_instrumental: true`.** Otherwise you roll the dice on a hummed hook.
- **Queue IDs expire.** A 404 on retrieve means requeue, not "poll harder."
- **402** is credits. Stop. Ours reset at 8 PM Eastern, so we queued the last five tracks after the reset.
- **Shorts are 3:00.** Muxed files overshoot. We capped generation at **179 seconds**, then `ffprobe` the file. YouTube Shorts is unforgiving.

Poll every ~20s. Save when the body looks like audio:

```python
def looks_like_audio(raw: bytes) -> bool:
    return (
        raw[:3] == b"ID3"
        or raw[:2] in {b"\xff\xfb", b"\xff\xf3", b"\xff\xf2"}
        or raw[:4] == b"RIFF"
    )
```

Then verify duration, don't trust the request:

```bash
ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1 track.mp3
```

**Listen to the first and last few seconds of every track.** Generated songs often start or end with junk. We found crackle before one track's intro, a nails-on-a-chalkboard screech in the last few seconds of another, and a stray blip at 1:57 of a third. Cut it and fade:

```bash
ffmpeg -y -i track.mp3 -t 116 -af "afade=t=out:st=113:d=3" -c:a libmp3lame -q:a 2 track-trimmed.mp3
```

When you hear a click in a stitched compilation, check *both* neighboring tracks before blaming one. The noise we heard "between 9 and 10" was the tail of track 9, not the start of 10.

**Regenerate freely.** We replaced eight of the twenty songs after living with the album for a few days. Keep the old take as `-v1.mp3`, generate a new one, and play them side by side. The review process is the same as for the first batch: play it in the local HTML, keep it or don't.

**Open with your strongest track.** We originally started the album at dusk. We moved Midnight Rooftop Flow to track 1 because it was the better song and more likely to keep people listening.

## 4. Dress the plate 🌙

Once the board is right, `image_edit` the **empty plate** with the boards as extra references:

1. Image 0: frozen empty rooftop (composition and lighting are law)
2. Image 1: Hero board
3. Image 2: Dimitris board

Ask for a **new pose**. Our first five dressed stills all used the same three-quarter "standing with laptop" stance. Cape On, IDE Open only started working when Hero *sat on the parapet* and Dimitris *stood behind him looking at the screen*.

**Add characters one at a time.** Two people in one edit usually meant one of them came out wrong, and each fix-up edit degraded both. Put the first character on the empty plate, approve it, save a copy, then add the second. If an edit leaves a faint mirrored "ghost" of a character on a wall or window, don't try to scrub it out with more edits. Go back to the untouched plate and make that one edit again.

**Check the output size after every edit.** One of ours quietly came back square instead of 16:9.

Keep the laptop a **small prop**, not a product shot. If the person holding it already wears a `</>` on the chest, the lid is a plain gold circle. A second emblem on the lid reads as a sticker. Keep the fire escape flat 2D if that's the bible. If the extra comes out jacked, long-armed, or huge-headed, *fix the board* and dress again — don't nibble the scene for an hour.

## 5. A loop that actually loops 🔁

`image_to_video` from the dressed still. Default 6 seconds.

**Decide the resolution before you generate twenty loops.** The xAI API supports 1080p for image-to-video on Imagine Video 1.5, but the Grok tool we used only offered 480p or 720p. So the album is 1280×720, and the 1080×1920 Shorts are upscaled crops of it. If you have API access, check what it offers first.

**Lock the camera, and say it like you mean it.** Camera drift was the most common reason we threw out a take: it happened on at least six of the twenty tracks. Once the framing zooms, no amount of trimming saves the join. The prompts that finally held stated the rules as non-negotiable and named exactly what stays still and what moves:

```
Non-negotiable: the camera stays locked. No zoom, no pan, no push-in.
Only animate the character in the black suit and the lobster.
The billboard and the hero stay absolutely static for the entire clip.
```

For Cape On, IDE Open, the prompt that behaved was **still wind, frozen cape, two tiny motions**:

```
Locked camera, this exact still. No wind. The magenta cape hangs frozen.
The sitting plum hero types on the gold laptop, fingers tapping keys.
The green sidekick stands solemnly in place and blinks occasionally.
Hero’s purple mask and solid white eyes never change.
Seamless loop, first frame equals last.
```

Then **measure**. Don't trust your eyes on a 6-second clip.

1. Extract every frame: `ffmpeg -i clip.mp4 -vsync 0 f%04d.jpg`
2. Downscale and compute mean absolute error of the **last frame vs every earlier frame**
3. Neighbor frames *inside the settled trim* are your noise floor — consecutive frames of the still-to-motion morph at the start of a take are ~0.7 and will lie to you. Real neighbors are ~0.2
4. Score a **crop of the sidekick's head**, not the whole 1280×720. Sky and buildings hide a 10px head jump in the average
5. Aim for a **3–6 second** window. Sub-2s loops look like a stutter
6. Trim from that `n` to the end with ffmpeg on the original mp4 (no JPEG-frame rebuild, no overlays) and play it with `<video loop>`

What we learned the hard way:

- **`image_to_video` is not a loop model.** "First frame equals last" is a wish. You search for a trim where the last frame matches some earlier frame. Check bounding-box width across frames to catch a slow zoom your eyes miss.
- **Cape motion is the default.** A waving cape looks alive and is easy to generate — and it usually won't match at the join. Frozen cape is harder: the model will steal motion into the head unless typing and a blink are named as the *only* motions.
- **Move eyes, not heads.** "Her eyes look at the screen and blink" loops. A head turn almost never comes back to the same angle.
- **Palindromes are a tool, not a failure.** Playing the approved span forward and then backward makes the join two neighboring frames. It saved four of our tracks, including a laptop that fades from red to gold and back. It fails on motion that has to travel one way — fog drifting across the frame — because backward fog looks wrong. For those, find a real cut or generate a scene without the directional motion.
- **Slowing down is allowed.** One loop felt busy at full speed and right at 75%. Same frames, stretched.
- **Don't overlay blinks onto a still cape.** You get JPEG mush. Generate until the take already has the blink.
- **White mask eyes drift, and "make them white" makes them worse.** Hero's lenses are slim blank ovals. Asking the still editor to fill them paints the chest emblem white and blows the eyes into circles. Animate from a still that already has the slim lenses, and say the eyes stay exactly as they are. Check a crop of the mask at both ends of the trim.
- **Check whether the problem is in the still or only in the video.** On one track, Hero grew pupils and lost his gloves in the animation while the still was fine. "Fixing" the still broke its style. Look at the source frame before you touch it.
- **Pin the first frame only when someone should talk.** Pinning the last frame to the same still pulls the mouth shut.
- **Let a person scrub the untrimmed take.** Frame-difference scores will call two frames a match while the head has rotated toward the moon. Open the full clip, step with the arrow keys, and cut where they say.

When last-vs-join on the *face crop* is close to a real neighbor, put it in the preview:

```html
<video autoplay loop muted playsinline src="videos/loops/01-cape-on-dusk-loop.mp4"></video>
```

Mux under the MP3 later. Imagine clips often carry their own AAC (silence, or a voice you did not ask for). Map the streams or that junk wins:

```bash
ffmpeg -y -stream_loop -1 -i loop.mp4 -i track.mp3 \
  -map 0:v:0 -map 1:a:0 -t "$DUR" -shortest \
  -c:v libx264 -pix_fmt yuv420p -preset fast \
  -c:a aac -b:a 192k -movflags +faststart \
  masters/track.mp4
```

Check the muxed duration with `ffprobe`. AAC wrapping adds a few frames.

## Ship the Short, bank the wide cut 📺

Every track wants two masters of the same song.

| Master | Shape | What it's for |
|---|---|---|
| 9:16 | 1080×1920 | The YouTube Short. One per track, one a day at 8 PM Eastern. |
| 16:9 | 1280×720 | The long cut. All twenty tracks stitched with short crossfades into one video of about 48 minutes. |

**Get the animation right in 16:9, then crop the Short from it.** Don't generate a separate portrait animation: it's a second lottery on the loop, and the two versions won't match. Cropping only goes one way — you can cut a 9:16 out of a 16:9 frame, never the reverse. When both characters won't fit in the crop, choose who stays. Our rule was Dimitris first, and for Waiting on CI we kept Hero, the laptop, and the moon.

```bash
ffmpeg -y -i loop-16x9.mp4 -vf "crop=405:720:410:0,scale=1080:1920" -c:v libx264 -pix_fmt yuv420p loop-9x16.mp4
```

Publishing the wide file as its own video spends the compilation. We sent one 16:9 plate to review by mistake and had to swap the attachment for the portrait.

If a tool will post the moment you click approve, set publish to **manual**. Approval and posting are different buttons.

**Put real fonts on text in images.** Image models approximate a typeface. For the album thumbnail we set the title in the site's actual font in an HTML page and screenshotted it, instead of asking the edit model to letter it.

## How You Can Do This 🛠️

**You need:** a Grok Imagine-capable client, a [Venice](https://venice.ai) API key, `ffmpeg`, and Python 3.

**Recipe:**

1. Write the slate on one page: title, seconds (vary them), BPM/key, who is in the shot.
2. Generate empty plates. Freeze the folder. Save the prompts.
3. Generate character boards on a flat background. Approve them *out of the scene*.
4. Queue instrumentals with `force_instrumental: true`. Poll retrieve until the body is an MP3. `ffprobe` durations. Listen to both ends.
5. Dress each plate with the boards as references, one character at a time. One new pose per track.
6. For a loop: locked camera (say it twice), name the only things that move, dump frames, score the *face crop* against real neighbors, then let a person pick the cut. Trim 3–6s, or palindrome the span if the motion can run backward.
7. Mux with `-map 0:v:0 -map 1:a:0`. Crop the 9:16 Short from the finished 16:9. Publish the Short. Keep the wide file.
8. Keep a local HTML so you can see the album as an album, not a pile of files.

**Budget your taste, not your GPU.** Stills and six-second clips are cheap. The expensive part is noticing that Dimitris is a green Hero, or that the loop zooms. That's the human job. It's also the [Automate It](https://automate.it.com) job: AI drafts, human approves, then it ships.
